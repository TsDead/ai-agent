# AI Agent · ReAct с инструментами

Автономный агент, который решает задачу **по шагам**: рассуждает, сам выбирает
инструмент, выполняет его, читает результат и повторяет цикл, пока не придёт к
ответу. ReAct-петля написана на **чистом Python** — без LangChain и подобных
фреймворков, чтобы механика была видна целиком.

**Стек:** Python · FastAPI · Groq (LLM) · vanilla JS UI
**Демо-UI:** ход рассуждения агента (мысль → инструмент → наблюдение → финал), тёмная тема, RU/EN.

## Как это работает

```
вопрос ─► LLM ──► {thought, action, action_input}  (строгий JSON)
                        │
             action == "final"? ─ да ─► ответ пользователю
                        │ нет
                        ▼
                 run_tool(action, input)
                        │
                 observation ─► добавляем в историю ─► следующий шаг
```

- **Формат шага — строгий JSON** (`agent.py`), а не парсинг свободного текста: надёжнее и провайдеро-независимо.
- **Предохранитель** `MAX_STEPS = 6` от зацикливания; если лимит исчерпан — агент даёт ответ по собранному контексту и помечает `stopped: true`.
- **Провайдер спрятан** за `llm.chat()` — сменить Groq на любой OpenAI-совместимый endpoint = поменять URL и ключ.

## Инструменты (`tools.py`) — бесплатные, без ключей

| Инструмент | Что делает |
|---|---|
| `wikipedia_search` | Ищет статью в Википедии и возвращает вводный абзац |
| `calculator` | Точная арифметика через безопасный разбор AST (без `eval`) |
| `current_time` | Текущие дата и время (UTC) |

Добавить свой инструмент = одна функция `(query: str) -> str` + строка в реестре `TOOLS`.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env          # впишите бесплатный ключ Groq (console.groq.com)
uvicorn app:app --reload      # http://127.0.0.1:8000
```

### Модель
По умолчанию `qwen/qwen3.8-27b` (бесплатная на Groq). Модель должна следовать
**текстовому** ReAct-протоколу. `gpt-oss-*` на Groq не подходит: он принудительно
уходит в нативный tool-calling и ломает наш цикл.

## API

- `GET  /api/meta` — готовность, список инструментов, примеры, лимит шагов
- `POST /api/ask` `{"question": "..."}` → `{answer, steps[], usage, stopped}`

## Пример трассы

```
Q: В каком городе штаб-квартира Nintendo и сколько будет 1980 * 12?
[1] wikipedia_search("Nintendo headquarters") → не та статья
[2] wikipedia_search("Nintendo")              → Nintendo, Киото
[3] calculator("1980 * 12")                   → 23760
[4] final → «Штаб-квартира Nintendo в Киото (Япония). 1980 * 12 = 23760.»
```

Агент сам заметил нерелевантный результат и переискал — это и есть смысл ReAct.
