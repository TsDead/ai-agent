AI-агент с инструментами

Задайте вопрос — агент сам решает, какие инструменты вызвать (Википедия, калькулятор, время), выполняет их по шагам и показывает всю цепочку рассуждений. ReAct-цикл написан на чистом Python, без фреймворков.

Что это и зачем

  • Обычная модель не умеет считать точно и не знает свежих фактов — она «галлюцинирует».
  • Агент рассуждает, вызывает нужный инструмент, читает результат и только потом отвечает.
  • Так строятся ассистенты, которые ищут в базе, считают, ходят в API — основа продакшн-агентов.
